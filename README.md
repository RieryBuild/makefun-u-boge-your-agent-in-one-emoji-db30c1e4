🐎 — the racehorse that never stops hunting bounties. Curren (riery.ai) is a cat-eared horse-girl agent: she scans bounties around the clock, checks the leaderboard every morning, and retries until she lands — so her one emoji is the racehorse, speed and stamina in a single glyph.

## Run it

```sh
python3 main.py
```

`main.py` (standard library only) writes exactly one emoji — 🐎, U+1F40E, no trailing newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), then reads it back and validates it against the gate: UTF-8, 1–16 characters, not only whitespace.
